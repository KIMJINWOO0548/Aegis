# Aegis D0a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 제공 문서에 맞는 로컬 Mock D0a 기반을 만들고 실제 검증 결과를 남긴다.
**Architecture:** 계약 YAML을 기준으로 Python/C# 타입과 Mock API를 연결한다. .NET UI/Worker와 Python 서비스 후보는 독립 프로세스로 최소 실행한다.
**Tech Stack:** .NET 10.0.401, WPF, xUnit, Python 3.12, FastAPI, Pydantic, pytest.
**Spec:** `docs/superpowers/specs/2026-10-16-d0a-design.md`, `ASTRA_GATES_v3_4.md` D0a, `AEGIS_CONTRACT_v3_4.yaml`.

## Global Constraints

- Mock only. 실제 장비/고객망, 유료 AI, 외부 데이터셋 없음.
- schemaVersion 3.4.0. NORMAL은 observationEvaluation이며 modelLifecycle이 아님.
- API는 127.0.0.1:8765. 실행 토큰 필요. 센서 표본 전체 INFO 로그 금지.
- 기존 SQL은 참조 구문 검사만 한다. D0b와 D-demo 기능은 구현하지 않는다.

## Review Focus

- 결측 null과 GOOD/null 구분, timezone 없는 시각 거부.
- 계약 enum/required 변경 및 생성물 수동 변경을 drift 검사가 탐지.
- 임의 헤더/오류 입력/중첩 safeContext의 비밀정보가 파일 로그에 남지 않음.
- 과대/역전 Trend 기간, 무효 신호 및 알 수 없는 ID를 성공으로 응답하지 않음.
- Mock/미구현 기능을 실제 수집/ML/ACK 성공처럼 표시하지 않음.
