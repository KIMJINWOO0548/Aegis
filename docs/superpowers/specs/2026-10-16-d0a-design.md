# D0a 개발 범위

사용자 요청: 제공된 폴더를 ponytail과 superpowers로 검토하고 개발 및 필요한 수정을 진행한다.
기존 `ASTRA_GATES_v3_4.md`의 D0a를 이번 작업의 범위로 적용한다. 새 프로젝트 기반 작업이며,
이미 제공된 제품 계획과 계약에 따라 최소 구현한다. 다음 Gate로 자동 진행하지 않는다.

## 구성

- 설치된 .NET SDK 10.0.401 고정, WPF 시작 화면, 공통 C# DTO, xUnit, Worker heartbeat.
- Python 3.12 가상환경, FastAPI 로컬 Mock API, Pydantic 계약, pytest.
- YAML enum/필수 필드와 OpenAPI 간 불일치 검사 및 생성물 drift 검사.
- observation/event/trend/timeline 타입. 결측값은 null이며 GOOD/null 조합은 거부.
- localhost API 토큰과 Host/Origin 검사. 요청별 requestId와 traceId를 전달한다.
- Trend/Timeline은 명시된 Mock 응답만 제공한다. EWMA, 시나리오 실행, ACK 저장은 이후 단계다.
- 구조화 JSONL은 허용된 메타데이터만 기록하며 비밀정보/원시 센서 payload를 차단한다.
- .NET/Python heartbeat 콘솔 스파이크를 실행하고 서비스 방식 ADR을 작성한다.

## 검증과 한계

계약 검사, pytest, xUnit, WPF build, heartbeat 실제 실행 결과를 남긴다.
Windows CI workflow는 작성하되 원격 저장소가 없어 실행하지 못하면 미검증으로 표시한다.
서비스 설치/자동시작/재부팅과 WPF DPI 검수는 실제 수행 여부를 구분한다.
G-LEGAL 체크리스트는 미확인 상태를 유지한다. 비상업 Mock 개발만 진행한다.
참조 SQL은 제품 DB로 사용하지 않는다. 기존 DOCX/PDF는 원본으로 보존한다.
