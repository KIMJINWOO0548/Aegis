# Aegis UI 외부 디자인 도구용 브리프

사용자 요청(2026-10-18): 적합한 MCP/플러그인을 연결하여 UI를 디자인한다.
선정: Product Design을 시안·프로토타입에 우선 사용하고 Figma를 편집/디자인 명세 반영에 사용한다.
사용자가 설치·연결 완료를 확인했고 두 플러그인의 스킬이 로드됐다. Product Design으로 시안을 생성하며, 선택 이후 편집 가능한 명세와 WPF 반영을 진행한다.

## 제품과 현재 화면

한국어 Windows 온프레미스 설비 상태 감시 앱. 구현은 WPF이며 웹 프레임워크로 바꾸지 않는다.
현재 화면은 `src/Aegis.Desktop/MainWindow.xaml`의 D0a 시작 화면이다. 실시간 Trend/ML/ACK 흐름은 아직 없다.
이 범위의 정보 계층·가독성·상태 표현을 개선한다. 이후 데모 화면을 제안한다면 미래 시안으로 명시한다.

## 전달 요구사항

- 설비 운영자가 대상 장비, 데이터 출처, 연결/모델 상태를 첫눈에 이해해야 한다.
- 장비 ID는 독자 작성 Mock EQ-SUPPLY-01. 실제 고객 정보/로그/비공개 문서는 외부에 전달하지 않는다.
- MOCK/SIMULATOR, 미연결/미확인, NO_MODEL을 정상 가동/경고 없음과 혼동하지 않게 표현한다.
- 가짜 경고 수치·실시간 그래프·확률·성능 지표·동작하지 않는 버튼을 넣지 않는다.
- 산업용 데스크톱 도구의 시각적 완성도와 한국어 가독성이 목표다. 장식용 사진·과도한 카드 중첩은 불필요하다.
- 기본 980×720, 최소 640×480에서 스크롤/줄바꿈을 유지한다.
- 키보드 포커스, 대비, 100%/150% DPI와 긴 한국어 문장을 고려한다.
- 편집 가능한 시안 및 색·서체·간격·상태 컴포넌트 명세를 받아 WPF 리소스/XAML에 반영한다.

시안과 실제 구현 화면을 비교하며 기능 검증과 시각 검증을 구분한다.

## 시안 선택 기록

Product Design의 ideate 절차와 내장 Image Gen으로 2026-10-18에 독립 시안 3개를 생성했다.
실제 대화에 표시된 순서가 선택 번호의 기준이다. 사용자는 1번 시안을 선택했다.

1. `design-concepts/aegis-ui-1.png`
2. `design-concepts/aegis-ui-2.png`
3. `design-concepts/aegis-ui-3.png`

공통 브리프: 한국어 Windows WPF의 장비 상태 첫 화면, Mock/미연결/모델 없음의 정직한 표시,
명확한 정보 계층, 가짜 측정값/고장 확률/장비 제어 없음. target 1440×1024, 날짜 기준 2026-10-18.
기존 코드와 요구사항을 텍스트로 제공했으며 기존 화면 스크린샷이나 Figma 원본을 첨부했다고 주장하지 않는다.
1번 이미지를 기준으로 WPF에 반영했다. 안내 버튼은 소유자가 있는 Mock 안내창을 연다.
실행 화면과 시안의 비교 및 검증 결과는 프로젝트 루트 `design-qa.md`에 기록한다.
Figma 파일 작성/편집은 수행하지 않았다. 이번 구현의 시각 기준은 Product Design으로 만든 선택 이미지다.
