# Aegis Windows 시연과 검증 범위

Aegis는 수집기로부터 받은 신호의 상태와 시각을 보여 주고, 사건에서 당시 원본으로 돌아갈 수 있는 읽기 전용 계측 도구입니다. 이 시연은 감자의 합성 수집기 두 개로 실행했습니다.

| 화면 | 확인할 내용 |
| --- | --- |
| [메인 작업대](images/windows-workbench/aegis-main.png) | 최대화한 화면에서 모듈 → 태그 → 추세·수신 품질을 한 번에 읽습니다. |
| [고정 신호 오버레이](images/windows-workbench/aegis-overlay.png) | 유량·압력·전류·온도·밸브 피드백을 동시에 표시합니다. |
| [작업대와 오버레이](images/windows-workbench/aegis-workbench-with-overlay.png) | 오버레이를 켜도 메인 작업대가 전경을 유지합니다. |

## Windows에서 써 보기

1. [Windows 실행 안내](../scripts/windows_release/README.ko.md)에 따라 포터블 작업대를 엽니다. 실행 화면에 합성 데이터 출처가 표시됩니다.
2. 두 모듈 중 하나를 골라 유량과 압력을 확인합니다. 작업대에서 관측 시각과 수신 시각을 비교하고 원본 보관 이력을 엽니다.
3. 트레이나 작업대 상단에서 오버레이를 켜고 필요한 태그를 고정합니다. 오버레이에는 고정한 신호의 값과 시각이 표시됩니다.
4. 합성 편차를 확인하려면 실행기에 `Aegis.cmd --workbench --scenario DEG-02`를 실행합니다. 이상 사건 화면에서 해당 근거를 보고 운영자 확인을 남깁니다. 다시 실행하면 이전 세션을 찾아볼 수 있습니다.

## 확인 범위

화면은 Windows 배율 125%에서 기본 계측 작업대를 최대화해 프로그램 커밋 `7d4727a`로 촬영했습니다. 이 Windows 후보에서는 합성 수집·복구, 사건 확인·이전 실행 보관 조회, 진단 미리보기와 로컬 파일 저장을 확인했습니다. 포터블과 설치 도구는 Windows x64와 WebView2 Runtime을 사용합니다.

현장 장비 연결, 현장 고장 탐지, 학습 모델의 자동 활성화, 깨끗한 Windows 환경, 공개 배포 서명, 150% 배율·다중 모니터는 별도 검증 항목입니다. 로컬 전체 회귀에서는 Windows 소켓 시작 오류와 링크·저장 시험 조건의 차이가 남았습니다. [하이브리드 검증 범위](HYBRID_DASHBOARD.md) · [저장소와 데이터 출처](SOURCE_CONTEXT_CONTRACT_20261109.md)
