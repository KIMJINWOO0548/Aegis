# ADR: D0a 착수 전 문서 및 계약 정합성

날짜: 2026-10-17. 사용자 지시: 검토 수정 후 개발 진행.

1. `ASTRA_GATES_v3_4.md`의 제품 계획 Markdown 참조는 존재하지 않는다. 실제 제공된 DOCX/PDF로 정정한다.
2. 로그 상세 명세는 v3.3 보존본이다. v3.4 실행 계약을 따르도록 머리말을 정정하고 과거 예제의 버전 표기를 구분한다. 원본 DOCX/PDF는 보존한다.
3. `Observation.value`는 필수 키이지만 결측 시 null을 표현해야 한다. 참조 SQL의 `GOOD`/non-null 제약과 상세 명세의 GAP 규칙에 맞춰 OpenAPI에 nullable을 허용하고, 모델에서 GOOD/null 조합은 거부한다. 참조 SQL을 제품 마이그레이션으로 사용하지 않는다.
4. Trend와 Timeline의 기존 OpenAPI는 중첩 객체의 필수 필드를 정의하지 않았다. 기존 YAML 예제에 따른 중첩 타입과 StructuredEvent를 명시한다. 경로와 기존 필수 필드는 유지한다.
5. v3.4 추가 이벤트는 기존 이벤트 목록과 합쳐 타입으로 생성한다. 기존 이벤트를 삭제하지 않는다.
6. 구조화 오류의 필수 `code/message/requestId`를 Mock API 및 명세의 오류 응답에 연결한다.
7. D0a의 서비스 비교는 콘솔 heartbeat와 패키징 기반 검증이다. 실제 서비스 설치·재부팅·자동시작은 D1이며, D0a 결과로 검증했다고 표시하지 않는다.
8. LOG-01~08은 제품 계획에 시험 주제가 있지만 ID별 상세 정의는 없다. 새 테스트는 의미 있는 이름을 사용하고, 기존 LOG ID 전체를 통과했다고 주장하지 않는다.

G-LEGAL은 미확인 상태를 유지한다. 이번 작업은 독자 작성 Mock 기반 개발이며 상업 배포·실장비·고객 데이터 접근을 포함하지 않는다.
